# Local fonts

Place the Eurostile `.ttf` files in this directory. Use descriptive filenames that include the weight and style, for example:

- `Eurostile-Regular.ttf`
- `Eurostile-Bold.ttf`
- `Eurostile-Italic.ttf`

The fonts can then be loaded once from `src/lib/fonts.ts` using `next/font/local`.
